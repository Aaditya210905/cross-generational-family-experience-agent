# FusionAI Frontend

A [Next.js](https://nextjs.org) application for the FusionAI family activity recommender.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Development

- The page auto-updates as you edit files in `app/` and `src/`
- API calls are proxied to `http://localhost:8000` via Next.js rewrites (see `next.config.ts`)
- Uses [Geist](https://vercel.com/font) font via `next/font`

## Tech Stack

- **Next.js** with App Router
- **TypeScript**
- **Tailwind CSS v4** with Turbopack

## Deploy

Deploy on [Vercel](https://vercel.com) — see [deployment docs](https://nextjs.org/docs/app/building-your-application/deploying).
